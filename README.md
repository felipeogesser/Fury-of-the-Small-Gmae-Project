# Fury of the Small

Fury of the Small é um jogo de estratégia e simulação em desenvolvimento, focado em batalhas automáticas entre exércitos compostos por centenas de pequenas entidades.

O projeto combina elementos de gerenciamento de vila, progressão de campanha e auto battler, inspirado em jogos como Total War: Warhammer 3, Clash of Clans e Dota Auto Chess.

## Objetivo

Criar um jogo open source que permita estudar e experimentar:

- comportamento coletivo (swarm behavior)
- inteligência artificial aplicada a grandes grupos
- batalhas automáticas entre exércitos
- otimização para suportar até 1000 entidades em tempo real

## Funcionalidades Planejadas

- gerenciamento de vila
- campanha com 30 fases
- generais e pelotões
- batalhas automáticas
- sistema de recompensa e progressão
- suporte a Linux e Windows
- mínimo de 60 FPS

## Tecnologias

- Linguagem C
- SDL2
- Git e GitHub

## Status

Projeto em fase inicial de prototipagem.
